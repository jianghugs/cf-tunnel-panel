Token 权限只要 Account · Cloudflare Tunnel · Edit 和 Zone · DNS · Edit 两项就够；再加上 Account · Account Settings · Read 和 Zone · Zone · Read，面板才能自动列出账号和域名。

      

      
边缘缓存

      
静态资源（/assets/*）本机已下发 Cache-Control: public, max-age=300 +
        Cloudflare-CDN-Cache-Control: max-age=86400。要让 Cloudflare 真缓存，还需要一条 Cache Rule
        （需 Token 带 Zone → Cache Rules → Edit；没有权限就去后台手建，表达式一样）。
