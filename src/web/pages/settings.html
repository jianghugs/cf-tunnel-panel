怎么申请隧道 token

在 Cloudflare 建一条隧道、拿到 token、接到出口里
展开看步骤与常见错误
  1. 打开 Cloudflare 控制台 → Networks → Tunnels → Create a tunnel → 选 Cloudflared → 起个名字保存。
  2. 页面给的安装命令里，--token 后面那串（184 字符、eyJh 开头）就是 token；也可以在 Tunnels 列表里这一行右侧的 token 图标再取一次（⋯ → Refresh token 会让旧 token 立刻失效）。
  3. 切到 Public Hostnames 加一条：Subdomain app → Service HTTP 127.0.0.1:8080（指向面板的 Caddy）。这一步不做，访问域名就是 1033。DNS 会自动生成 CNAME <tunnelId>.cfargotunnel.com，确认是橙云（Proxied）。
  4. 回面板 出口 → 命名隧道 粘贴 token 并保存。整条 docker run … --token eyJ… 命令直接粘进去也可以，面板会把 token 抠出来。
  5. 验收：curl -sI https://<域名> 返回 200/302 且带 cf-ray；面板「一键体检」里的「出口」一项会同时看进程与公网可达性。

更省事的做法：出口页右上角「一键新建出口」会一次做完「建隧道 → 取 token → 写 ingress → 建 CNAME → 本地接入」，勾「只演练」可以先看计划。完整版见 docs/CLOUDFLARE-TUNNEL.md。

现象原因 / 处理
1033隧道没写 ingress（Public Hostnames 没加）
530 / 502隧道通了但 Caddy 没接住：上游挂了或规则没命中，去「规则 → 模拟匹配」查
显示「尚未检测到连接」token 复制不全，或被 Refresh 过
重连次数一直涨QUIC 被中途掐断：出口协议从 auto 改 http2

掉线通知

出口掉线 / 换域名 / Caddy 下发失败时推一条
通知通道（可以同时配多个，各自独立启用）
名称格式地址加签密钥启用操作
比如出口掉线后 5 分钟内只提醒一次，避免反复刷屏；0 = 不冷却
这段时间内不发通知（可跨零点，多段用逗号：12:00-13:30,23:00-07:00）
占位符：{event} {title} {text} {host} {time} {running} {total}
例：{time}｜{host}｜在线 {running}/{total}

面板登录

设置后浏览器会弹 HTTP Basic 登录框

登录会话

谁在什么设备上登录着，可以逐个踢掉
一个会话 = 一次登录：7 天免密、12 小时不动就失效。踢掉后那台设备需要重新登录。同一会话换了来源 IP 会打「换过 IP」标记并推一条通知（改面板口令会自动踢掉所有会话）。
账号角色来源 IP设备登录时间最后活动

只读账号

给「只想看看状态」的人：能看所有页面，改不了任何配置
只读账号用浏览器 Basic 登录，GET 一律放行、写操作返回 403。首次设置必须同时给密码。

二次验证（TOTP）

手机验证器 App 的 6 位数字，登录时多一道关
开启后，浏览器登录要先输口令、再输验证器里的 6 位数字。curl / 脚本仍可用 Basic（当作机器凭证），所以别把账号口令写进公共脚本。
用 Google Authenticator / 1Password / Authy 扫码
这些恢复码只显示这一次，请立刻抄到安全的地方（每张纸只能救一次命）。
